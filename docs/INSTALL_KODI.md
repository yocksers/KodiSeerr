# Install KodiSeerr in Kodi

## 1) Install the KodiSeerr repository ZIP

1. Download `repository.kodiseerr-<version>.zip` from this repository's releases.
2. In Kodi, open **Add-ons**.
3. Select the package icon, then choose **Install from zip file**.
4. Select the downloaded `repository.kodiseerr-<version>.zip` file.

## 2) Install KodiSeerr from repository

1. In Kodi, choose **Install from repository**.
2. Open **KodiSeerr Add-ons**.
3. Install **KodiSeerr**.

## 3) Updates

After installation from the repository, KodiSeerr updates are delivered through Kodi's normal add-on update mechanism.
